#  نظام العرب (Arab OS) 🌙️⚔️



## عن المشروع 💻
المشروع عبارة عن نظام تشغيل عربي ، يُبنى ليكون بيئة برمجية متجانسة لتوفير نظام تشغيل مستقل.

---

## بطاقة تعريف النظام 📋

| الخاصية | التفاصيل |
| :--- | :--- |
| **اسم المشروع** | نظام العرب |
| **نوع المشروع** | نظام تشغيل (Operating System) |
| **منشئ المشروع** | سيف حسين |
| **لغة التطوير** | السي (C) |
| **إصدار المشروع** | 4.1 (تجريبي - قيد التطوير) |
| **تاريخ الإصدار** | 27 ذو الحجة 1447 هـ \| 13 يونيو 2026 م |
| **رخصة المشروع** | GPL-2.0 / رخصة المطورين العرب العمومية (ARDB-1.0) |

---

## إخلاء المسؤولية ⚠️
> **تنبيه:** النظام لا يزال في مرحلة تجريبية وتحت التطوير المستمر. لا يتحمل المطور أي مسؤولية عن أي سوء استخدام أو أضرار قد تنتج عن تشغيل النظام. تجربة النظام تقع على عاتق المستخدم بالكامل.

### 🚀 كيفية البناء


`make للبناء فقط نفذ الامر  `
`make run نفذ الامر للبناء والتشغيل معا `
